# Lessons

One file per PR, written before it merges: `<pr>-<short-name>.md` with `# Title · date`, then **Numbers** (cost against the brief's estimate, pushes, red CI runs, time waiting on the owner), **Went well** and **Lessons**, a line per lesson. A lesson that would have saved real time or credits changes the playbook, check or tool that allowed it, in the same PR, marked with → and where.
